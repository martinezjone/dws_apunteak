# Unitatea 1: Web arkitektura eta garapen-tresnak

Web orri bat deskargatzen dugunean, haren edukiak zehazten du pantailan agertuko dena (HTML).  
Ondo egituratua badago, estilo-orria (CSS) izango du, orriaren atal bakoitzaren estiloa nabigatzaileari adierazteko.  
Bezero–zerbitzari komunikazioari deitzen zaio, non bezeroak (nabigatzailea) eskaera (request) bidaltzen duen eta zerbitzariak erantzun (response) bueltatzen duen.

## Lan eremua prestatzen

Ikasgai honetan lan egiteko, web zerbitzari bat sortuko dugu gure ekipoetan. Horretarako, erabiliko ditugun tresnak honako hauek dira:

[XAMPP](https://www.apachefriends.org/index.html): Apache, MariaDB, PHP eta Perl biltzen dituen paketea

[MAMP](https://www.mamp.info/en/): Apache, MySQL, PHP eta Perl biltzen dituen paketea (Mac eta Windows bertsioak)

[Laragon](https://laragon.org/): Windows-erako garapen-eremua, Apache, MySQL/MariaDB, PHP, Node.js eta gehiago barne

[Postman](https://www.postman.com/): API-ak eta HTTP eskaerak probatzeko tresna grafikoa


[Visual Studio Code](https://code.visualstudio.com/): gure kodea editatzeko IDE nagusia


Beste beharrezko konfigurazio, plugin eta luzapenak azalduko ditugu, hala nola PHP Debug, IntelliSense eta Git integrazioa.
