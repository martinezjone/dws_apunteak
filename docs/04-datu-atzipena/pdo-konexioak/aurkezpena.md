# PDO Konexioak - Aurkezpena

## Helburuak

### Ikasgai honen helburu nagusiak:
- PDO (PHP Data Objects) zer den ulertzea
- Nola konektatu datu-base batera PDO erabiliz
- Nola exekutatu kontsulta sinpleak eta konplexuak
- Nola erabili prepared statements segurtasun-arrazoiak direla-eta
- Transakzioak nola erabili datu-koherentzia mantentzeko
- Erroreak nola kudeatu modu egokian

## Edukiak

1. **PDO Sarrera**
   - Zer da PDO eta zergatik erabili
   - PDOren abantailak
   - PDO vs MySQLi vs mysql_* funtzioak

2. **Konexioa sortu**
   - DSN (Data Source Name) konfigurazioa
   - Konexio-akatsen kudeaketa
   - Konexioaren ezaugarriak konfiguratu

3. **Kontsultak exekutatu**
   - Query sinpleak
   - Prepared statements
   - Parametroak lotu
   - Emaitzak lortu

4. **Transakzioak**
   - Transakzioen kontzeptua
   - Transakzioak hasi, onartu eta atzera botatzea
   - Errore-kudeaketa transakzioetan

5. **Errore-kudeaketa**
   - PDOren errore-moduak
   - Salbuespenak kudeatzea
   - Errore-mezu pertsonalizatuak

## Aurreko ezagutzak

Ikasgai honetarako beharrezkoak diren aurreko ezagutzak:
- PHP oinarrizko sintaxia
- MySQL/SQL kontsulta oinarrizkoak
- Datu-baseen kontzeptu orokorrak

## Hurrengo pausuak

Ikasgai honen ondoren, hurrengo gaietara joango gara:
- ORM (Object-Relational Mapping) kontzeptua
- Laravel Eloquent erabiltzea
- Datu-baseen migrazioak eta seed-ak
